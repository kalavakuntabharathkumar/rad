# Accessibility QA checklist (WCAG 2.1 AA target)
- [ ] All actions work by keyboard and focus order is logical.
- [ ] Visible focus indicator is present.
- [ ] Headings form a meaningful hierarchy.
- [ ] Data tables have captions and scoped headers.
- [ ] Status/error updates are announced with live regions.
- [ ] Color is not the only signal for risk band; text labels are present.
- [ ] Contrast checked with an automated tool and manual review.
- [ ] Test with NVDA/VoiceOver and browser zoom at 200%.
- [ ] Run Lighthouse and axe; do not claim compliance from a score alone.
